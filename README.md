# 数智天力协同管理平台 · 前端 Demo

根据《内部信息管理系统前端Demo需求文档模板》实现的零依赖高保真前端原型。

## 运行方式

直接双击 `index.html` 即可运行。为获得更稳定的本地存储行为，也可以在本目录启动任意静态文件服务器后访问首页。

例如：

```powershell
python -m http.server 5173
```

然后访问 `http://127.0.0.1:5173/`。

## 已实现范围

- 生产经营计划：搜索、分类标签、筛选、排序、新增、编辑、详情、删除/归档、分页状态。
- 采购计划管理：应急/常规采购切换、常规采购工作表、收藏与临时录入。
- 产品质量管理：实物标签图片上传、生产详情子工作表与批次录入。
- 其余业务模块：保留左侧一级导航入口与演示反馈。
- 数据仅保存在浏览器 `localStorage`，可使用工具栏重置按钮恢复空表状态。
